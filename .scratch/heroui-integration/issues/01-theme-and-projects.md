# 01: 统一 HeroUI 主题与项目入口

**What to build:** 学习者可从全局可见的项目侧栏切换浅色和深色模式，刷新后保留偏好，并在两种主题下完成项目选择、刷新、编辑和确认删除。切换主题不改变当前项目或编辑草稿，打开的弹窗和 Tooltip 同步使用 HeroUI 的主题。

**Blocked by:** None (can start immediately).

**Status:** done (2026-10-10)。验收记录：`.scratch/heroui-integration/records/01-theme-and-projects.md`。
