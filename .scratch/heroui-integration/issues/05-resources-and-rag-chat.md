# 05: 完成 HeroUI 资料上传与 RAG 问答

**What to build:** 学习者在两种主题下选择知识点、上传并索引资料、确认删除资料，再选择已索引资料提问、查看流式回答与引用、停止或重试问答；整个流程保持资料范围和操作状态清晰可辨。

**Blocked by:** 02 — 完成 HeroUI 工作区导航与进度。

**Status:** ready-for-agent

依据规格《统一前端 HeroUI 基础控件与浅色/深色主题验收》。本任务保持资料上传和问答的现有 REST、SSE 与数据契约，不需要修改索引或模型配置业务。

- [ ] 资料库知识点选择、刷新、上传、删除、确认输入及取消使用适当的 HeroUI 控件；文件输入可保留浏览器原生实现，登记理由并验证标签、焦点、禁用及主题表现。
- [ ] 上传文件格式、请求数据和索引进度保持现有行为；上传/删除期间防止重复提交或修改会导致操作目标混淆的选择，错误显示明确文字并允许合理重试。
- [ ] 删除资料保留后端给出的确认词，只有精确匹配才能提交；提交中禁止重复确认或关闭正在进行的确认操作，失败保留输入与错误，成功刷新对应资料。
- [ ] RAG 知识点选择、资料 Checkbox、问题 TextArea、提问、停止与重试使用 HeroUI，保留现有资料集合及选择范围，不改变引用或历史请求结构。
- [ ] 没有可问答资料、没有选中资料、范围读取中、问答进行中和连接失败均有明确反馈；资料长标题和勾选状态可通过键盘访问。
- [ ] 流式回答继续逐步呈现，停止仍中断当前请求，重试仍使用上次问题；引用内容和会话文本保持两种主题下的可读性。
- [ ] 切换主题保留节点选择、待上传文件、资料勾选、问题草稿、消息与引用；不会重启上传、清空会话或中断正在进行的 SSE。
- [ ] 在 API 客户端处模拟上传与问答事件，真实渲染 HeroUI，验证文件选择与上传进度、删除确认、资料勾选、提问范围、流式输出、停止和重试，以及相关禁用和失败反馈。
- [ ] 完成浅色、深色及往返切换浏览器验收，包括选择器浮层、长资料名称、引用展开、窄屏、键盘焦点，以及上传和回答进行中的主题切换，记录证据。
- [ ] 更新控件来源、原生文件控件例外和主题验收记录，只清理本任务已无调用方的重复控件规则；类型检查、完整前端测试和静态生产构建通过。
