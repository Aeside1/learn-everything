# Domain Docs

This repository uses a single domain context.

Before exploring a feature, read `CONTEXT.md` at the repository root and relevant records under `docs/adr/`. If these files do not exist yet, proceed without treating their absence as a blocker.

Use terminology from `CONTEXT.md` in issue titles, specifications, tests, and implementation notes. When a new domain term is unresolved or overloaded, record the decision through domain modeling before implementation.
