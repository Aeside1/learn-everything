# Issue tracker: GitHub

Issues and specs for this repo live in GitHub Issues. Use the `gh` CLI for all operations.

## Repository

Issues live in `Aeside1/learn-everything`.

## Conventions

- Create an issue with `gh issue create --repo Aeside1/learn-everything`.
- Read an issue with `gh issue view <number> --repo Aeside1/learn-everything --comments`.
- List issues with `gh issue list --repo Aeside1/learn-everything`.
- Comment with `gh issue comment <number> --repo Aeside1/learn-everything`.
- Apply or remove labels with `gh issue edit <number> --repo Aeside1/learn-everything`.
- Close with `gh issue close <number> --repo Aeside1/learn-everything`.

## Pull requests as a triage surface

PRs as a request surface: no.
